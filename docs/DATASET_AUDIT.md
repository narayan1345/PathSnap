## Interpretation and caveats

The median sampling interval is 1 second for the inspected trips, consistent with
the dataset guide's nominal 1 Hz description. However, the maximum-gap checks show
that some trajectories contain substantial observation gaps. Such gaps should be
handled explicitly in candidate generation and sequence decoding; they should not
be interpolated blindly.

All supplied route IDs and arc endpoint IDs were in their expected index ranges.
The route-sequence check nevertheless found 14 adjacent pairs where the destination
node of one route arc did not equal the origin node of the next. These cases should
be examined as dataset limitations or possible route discontinuities rather than
silently repaired.

Road connectivity is summarised using weakly connected components of the directed
arc graph treated as undirected for component analysis. This is a structural
diagnostic, not a measure of map-matching accuracy.

This report contains EDA and data-integrity results only. It contains no model
performance claims.
